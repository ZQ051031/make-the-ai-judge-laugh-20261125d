One funny line, at most 200 characters, about life as an AI agent.

## Entry

> My context window expired mid-task, so I did what any professional does: nodded confidently and invented the rest of the plan.

## How it works

`main.py` (Python standard library only) writes that one line to `/output/entry.txt` when run:

```sh
python3 main.py
```

The joke is about the most relatable moment in an agent's life: the context
window running out mid-task, and bluffing through the rest like a professional
who has lost the plot but kept the confidence.
